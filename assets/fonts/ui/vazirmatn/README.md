# Vazirmatn UI font assets

- **Upstream:** `rastikerdar/vazirmatn`, release tag `v33.003`
- **Source files:** `fonts/ttf/Vazirmatn-Regular.ttf`, `Vazirmatn-Medium.ttf`, `Vazirmatn-SemiBold.ttf`, and `Vazirmatn-Bold.ttf`
- **License:** SIL Open Font License 1.1; see the adjacent `LICENSE.txt`
- **Use:** optional Flutter UI font family `Vazirmatn`, registered at weights 400, 500, 600, and 700 in `pubspec.yaml`

These are the standard Vazirmatn TTFs from the supplied v33.003 ZIP. Official PDF/report output uses the distinct Farsi-Digits variant in `assets/fonts/vazirmatn/` and must not be redirected to this UI family. The canonical default UI font remains VazirHarf.
