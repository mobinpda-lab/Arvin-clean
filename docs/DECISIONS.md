# Arvin Decisions

## Purpose
Record important decisions so development can continue after interruption.

## Decision: PR Handling
Old PRs must not block production progress. Historical evidence may be kept, but active work follows one canonical path.

## Decision: Release Speed
RC work is isolated from future features. New capabilities continue in parallel only when they cannot delay release.

## Decision: Automation
Repeated checks and reporting should move to automation whenever possible.

## Decision: Documentation
Use periodic checkpoints and important-event updates without creating unnecessary overhead.
