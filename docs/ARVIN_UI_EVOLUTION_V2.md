# ARVIN UI EVOLUTION V2

## هدف
جایگزینی رابط کاربری فعلی آروین با UI تاییدشده توسط مالک پروژه. تصاویر مرجع، قرارداد طراحی هستند و فقط الهام نیستند.

## اصول
- Flutter Android واقعی، نه موکاپ.
- حفظ مدل‌ها، سرویس‌ها و ذخیره‌سازی فعلی.
- عدم ایجاد مسیر موازی برای Task، FollowUp و Notebook.
- رابط کاملاً فارسی و RTL.
- حفظ فونت VazirHarf v34.003.

## طراحی
- رنگ اصلی: #4A4CAB
- زمینه: #F8F8FB
- کارت سفید، گوشه نرم، سایه ظریف.
- آیکون‌های هماهنگ با تصاویر مرجع.

## صفحه اصلی
- حفظ عنوان آروین و هویت بالای صفحه.
- حذف کارت‌های آماری.
- چهار مسیر اصلی:
  - زمان
  - پروژه‌ها
  - دسته‌ها
  - برچسب‌ها
- انتخاب هر مسیر باید گروه‌بندی واقعی داده‌ها را تغییر دهد.

## نماها
### زمان
عقب‌افتاده، امروز، آینده، بدون موعد.

### پروژه‌ها
گروه‌بندی کارها بر اساس پروژه، بدون پروژه، افزودن سریع کار.

### دسته‌ها
مستقل از پروژه، دارای آیکون و رنگ.

### برچسب‌ها
پشتیبانی از چند برچسب برای هر کار بدون تکثیر داده.

## ثبت سریع کار
- پنل سریع مطابق تصاویر.
- ثبت پیاپی بدون بسته شدن پنل.
- حفظ انتخاب‌های مشترک.
- جلوگیری از ثبت تکراری.
- فرم کامل همان پیش‌نویس را دریافت کند.

## کارت کار
نمایش:
- وضعیت انجام
- عنوان
- پروژه/دسته
- موعد
- آخرین پیگیری یا توضیح کوتاه

## Swipe
- چپ: انجام و تغییر تاریخ.
- راست: جابه‌جایی و حذف.
- تست واقعی RTL الزامی است.

## دفترچه
- یادداشت‌ها و چک‌لیست‌ها مطابق تصاویر.
- جستجو و دسته‌بندی.
- ویرایش خلوت و تمام صفحه.

## تقویم
تقویم شمسی واقعی با تفکیک کار، پیگیری و یادآور.

## تحویل
قبل از اعلام تکمیل:
- flutter analyze
- تست‌ها
- بررسی Android واقعی
- اسکرین‌شات و گزارش تغییرات

بازخوردهای ثبت‌شده مالک پروژه در نسخه‌های قبلی باید حفظ و بررسی شوند و هیچ موردی حذف نشود.
