# Arvin Continuation Command

## Permanent project rule

The exact user phrase:

`ادامه آروین`

is an execution command for continuing the Arvin project. It is not merely a closing phrase.

When this command is received, the continuation process should:

1. Audit the real current GitHub/project state.
2. Identify the next real unfinished work.
3. Continue safe, evidence-based execution where available.
4. Use parallel and simultaneous work for independent tasks whenever possible.
5. Preserve quality, architecture, testing, CI/validation, rollback safety, and avoid duplicate work.

## Speed principle

**سریع + همزمان + موازی + کنترل‌شده**

The project goal is to move from work that takes days toward work completed in hours, without sacrificing quality or safety.

## Response-format rule

At the end of every Arvin-related response, the exact phrase below must appear in a standalone copyable code block and nothing else may be inside that block:

```text
ادامه آروین
```

No box, symbols, label, or additional text may be placed inside that block.

## Governance

This rule is a project continuation convention. It does not authorize destructive or unsafe changes. Real repository evidence remains the source of truth, and changes should follow the project's audit/review/validation gates.
