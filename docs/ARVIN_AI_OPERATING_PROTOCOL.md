# Arvin AI Operating Protocol v38.0

## Before Action
1. Read documentation.
2. Audit GitHub state.
3. Check branch, commit, PR and workflow.
4. Identify the real gap.
5. Make the smallest effective change.

## Execution
- Implement
- Test
- Validate
- Document
- Provide evidence

## Rules
AI must not assume state, duplicate existing capability, or report success without evidence.

## Continuation
New AI or teams continue from repository state, documentation and evidence. The project does not restart from zero.
