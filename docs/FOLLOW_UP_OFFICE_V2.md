# دفتر پیگیری آروین

این Wave دفتر پیگیری را به‌عنوان یک سطح مستقل UI تعریف می‌کند.

- تاریخچه پیگیری‌ها به‌ترتیب جدیدترین نمایش داده می‌شود.
- هر رکورد می‌تواند یادداشت، نتیجه و پیگیری بعدی داشته باشد.
- تاریخ و ساعت با ارقام فارسی نمایش داده می‌شوند.
- داده‌های قدیمی که فقط `followUpDate` دارند به یک رکورد مهاجرتی تبدیل می‌شوند.
- منبع حقیقت همان ذخیره‌سازی `arvin.tasks` است.
- اتصال مستقیم صفحه به HomePage و فرم ثبت چندپیگیری در Wave بعدی انجام می‌شود تا این Wave مستقل و قابل تست بماند.
