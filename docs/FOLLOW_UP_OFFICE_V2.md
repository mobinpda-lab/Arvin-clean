# دفتر پیگیری آروین — V2

## هدف

دفتر پیگیری یک بخش مستقل از آروین است؛ هر کار می‌تواند چند رکورد FollowUp داشته باشد و تاریخچه آن‌ها از جدیدترین به قدیمی‌ترین نمایش داده می‌شود.

## هر رکورد

- تاریخ و ساعت پیگیری
- یادداشت
- نتیجه
- پیگیری بعدی (در صورت وجود)

## قواعد UI

- رابط کاملاً فارسی و RTL است.
- تاریخ/ساعت با ارقام فارسی نمایش داده می‌شود.
- فیلتر «فقط پیگیری‌های آینده» وجود دارد.
- وضعیت Task با تاریخچه FollowUp یکی نیست.

## معماری

`TaskStore` منبع حقیقت باقی می‌ماند و `FollowUpOfficePage` فقط presentation است. اتصال این صفحه به HomePage و فرم ثبت FollowUp در Wave بعدی انجام می‌شود تا این Commit مستقل و قابل Validation باقی بماند.
