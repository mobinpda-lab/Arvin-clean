# ماتریس تأیید منابع «پیام روز» آروین — 2026-08-27

Refs: #260

## اصل حاکم
منبع علمی معتبر با «مجوز استفاده production/API» یکی نیست. هیچ منبعی فقط به‌دلیل معتبر بودن علمی، dependency مستقیم محصول محسوب نمی‌شود.

| دسته | مرجع علمی/تطبیق پیشنهادی | نقش فعلی | شرط ورود به production |
|---|---|---|---|
| قرآن کریم | مرکز طبع و نشر قرآن جمهوری اسلامی ایران + مراکز معتبر قرآنی حوزوی | متن/تطبیق | متن/ترجمه قابل انتساب + هماهنگی/مجوز استفاده نرم‌افزاری |
| حدیث شیعه | پژوهشگاه قرآن و حدیث/دارالحدیث + جامع‌الاحادیث نور | مأخذ و تطبیق | گوینده + کتاب + شماره/جلد/صفحه + وضعیت اعتبار در صورت وجود + اجازه استفاده |
| نهج‌البلاغه | منابع حوزوی معتبر قم/نجف؛ پایگاه الشیعه وابسته به دفتر آیت‌الله سیستانی به‌عنوان مرجع تطبیق | تطبیق خطبه/نامه/حکمت | فراز مستقل + شماره دقیق + ترجمه مجاز؛ عدم scrape مستقیم |
| صحیفه سجادیه | پژوهشگاه قرآن و حدیث و منابع حوزوی معتبر؛ الشیعه برای کتاب‌شناسی/تطبیق | تطبیق دعا/فراز | شماره دعا/فراز + ترجمه مجاز؛ عدم scrape مستقیم |
| بزرگان ایران | اثر اصلی یا مؤسسه رسمی نشر آثار هر شخصیت | منبع اولیه | مأخذ مشخص و حق استفاده روشن |
| بزرگان جهان | اثر/سخنرانی/آرشیو اولیه قابل راستی‌آزمایی | منبع اولیه | متن اصلی + مأخذ + ترجمه کنترل‌شده |

## یافته‌های دسترسی تأییدشده در بررسی 2026-08-27
### قرآن — مرکز طبع و نشر قرآن جمهوری اسلامی ایران
- مرکز فایل قرآن مخصوص کاربران فضای مجازی و طراحان نرم‌افزار قرآنی ارائه می‌کند و برای آن پشتیبانی فنی اعلام کرده است.
- هم‌زمان، متن شرایط مرکز تصریح می‌کند فایل تحویلی نباید دست‌کاری شود و استفاده خارج از توافق/بدون اطلاع و نظارت مرکز ممنوع است.
- نتیجه اجرایی: این مرکز گزینه بسیار قوی برای متن مرجع است، اما قبل از provider تولیدی آروین باید نوع استفاده «پیام روز» و روش دریافت/بازنشر با مرکز هماهنگ شود. دانلود فایل به‌تنهایی مجوز عمومی API محسوب نمی‌شود.

### نهج‌البلاغه و صحیفه — پایگاه الشیعه
- پایگاه الشیعه خود را وابسته به دفتر آیت‌الله العظمی سید علی سیستانی و مستقر در قم معرفی می‌کند و محتوای نهج‌البلاغه/صحیفه دارد.
- سایت اعلام می‌کند حقوق مادی و معنوی آن محفوظ است.
- نتیجه اجرایی: مرجع مناسب حوزوی برای تطبیق و بررسی، نه provider قابل scrape تا زمان اخذ اجازه/روش رسمی.

### حدیث روز — دارالحدیث/حدیث‌نت
- سامانه `dailyhadith.ir` در وب با عنوان «سامانه هوشمند حدیث روز» قابل شناسایی است و `hadith.net` به‌عنوان پایگاه اطلاع‌رسانی حدیث شیعه شناخته می‌شود.
- در بررسی فعلی، مستند عمومی و قابل اتکای REST API/مجوز بازنشر که بتوان آن را بدون هماهنگی dependency تولیدی اعلام کرد بازیابی نشد.
- نتیجه اجرایی: اولویت تماس/هماهنگی برای source adapter حدیث است؛ تا زمان تأیید endpoint/شرایط استفاده، داده آن به‌صورت scrape مستقیم وارد production نمی‌شود.

## Guardrails
- scraping مستقیم سایت‌های حوزوی یا مؤسسات رسمی، بدون اجازه/قرارداد روشن، provider production نیست.
- API عمومی ناشناس یا aggregator نقل‌قول، منبع اعتبار حدیث/قرآن محسوب نمی‌شود.
- ترجمه ماشینی متن دینی به‌عنوان ترجمه نهایی publish نمی‌شود.
- «در کتاب شیعی آمده» به‌تنهایی معادل «صحیح‌السند» نیست.
- اگر source/reference/verification ناقص باشد آیتم باید fail-closed شود.
- بسته‌های محتوا کوچک و versioned می‌مانند؛ کتاب کامل وارد APK نمی‌شود.

## وضعیت اجرایی
- لایه مدل و selector در main موجود است.
- UI، codec، preferences و notification به‌صورت PRهای مستقل در حال validation هستند.
- انتخاب provider واقعی تا تأیید روش دسترسی/مجوز از توسعه UI جدا نگه داشته می‌شود تا delivery متوقف نشود.

## اقدام بعدی منبع
برای هر دسته باید یک «source adapter approval record» ثبت شود که شامل نام مؤسسه، endpoint/روش دریافت، شرایط استفاده، تاریخ بررسی و مسئول تأیید باشد. اولویت عملی تماس/تأیید: 1) مرکز طبع و نشر قرآن برای استفاده نرم‌افزاری آیات، 2) پژوهشگاه قرآن و حدیث/دارالحدیث برای حدیث روز، 3) منبع ترجمه مجاز نهج‌البلاغه و صحیفه.
