# Arvin Master Operating Document v38.0

## Purpose
Arvin is a software factory model for fast, parallel, controlled production of real software.

## Source of Truth
GitHub Repository state is the authority:
- source code
- branches
- commits
- pull requests
- workflows
- tests
- builds
- documentation

No progress claim is valid without evidence.

## Core Principles
1. Independent work runs in parallel.
2. Dependencies require coordination.
3. Foundation changes require controlled review.
4. Changes must be testable and reversible.
5. CI and validation are part of development.
6. Working software is the final objective.

## Architecture
Clean Architecture + Feature Based Architecture.
