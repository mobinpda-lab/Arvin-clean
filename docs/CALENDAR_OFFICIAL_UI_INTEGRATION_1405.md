# اتصال تعطیلات رسمی ۱۴۰۵ به UI تقویم

## مسیر اجرا

`IranianOfficialHolidaySource` فقط دادهٔ ممیزی‌شده را تولید می‌کند. این داده از
`OfficialCalendarReminderService` عبور می‌کند و در `OfficialCalendarPage` با
یادآوری‌های فعلی ادغام می‌شود؛ خروجی نهایی همان `CalendarReminder` موجود است و
بدون storage یا مدل تقویم موازی به `CalendarPage` تحویل داده می‌شود.

برای سند رسمی ۱۴۰۵ هر دو بخش میلادی 2026 و 2027 بارگذاری می‌شوند، زیرا سال
شمسی ۱۴۰۵ در مرز این دو سال میلادی قرار دارد.

## قرارداد UI

- تعطیلات رسمی به‌صورت رویداد تمام‌روز نمایش داده می‌شوند.
- برای تعطیلی نیمه‌شب ساختگی (`۰۰:۰۰`) یا وضعیت «در انتظار پیگیری» نمایش داده نمی‌شود.
- یادآوری‌های زمان‌دار فعلی، ساعت و وضعیت انجام را مانند قبل حفظ می‌کنند.
- صفحه و متن‌ها RTL و فارسی باقی می‌مانند.
- خطای بارگذاری، پیام فارسی و امکان تلاش دوباره دارد.

## محدوده

این برش فقط مسیر Provider → Service → CalendarPage را تثبیت می‌کند. اتصال ورودی
صفحه به ناوبری Home پس از تثبیت شاخهٔ مهاجرت Home انجام می‌شود تا دو مسیر موازی
روی یک فایل مشترک تداخل نداشته باشند.

## اعتبارسنجی

- تست service برای نگاشت تعطیلی به قرارداد تمام‌روز.
- تست widget برای ادغام خروجی رسمی و یادآوری فعلی در CalendarPage.
- تست regression برای حذف ساعت و وضعیت ساختگی از تعطیلی تمام‌روز.
