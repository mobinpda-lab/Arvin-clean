# راهنمای درون‌صفحه‌ای آروین — 2026-08-27

## وضعیت
این تغییر ادامه مستقیم راهنمای مصور و راهنمای تعاملی صفحه اصلی است. هدف این مرحله این است که راهنما فقط زمانی نمایش داده شود که خود کاربر آن را بخواهد و برای همان صفحه توضیح کوتاه و کاربردی بدهد.

- عملیات اصلی صفحه با اضافه شدن راهنما تغییر نمی‌کند.

- متن‌ها فارسی، RTL، کوتاه و غیر فنی هستند.
- بستن راهنما هیچ داده‌ای را تغییر نمی‌دهد.

## اجرای موازی و GitHub Automation
`Arvin Parallel Wave` یک surface مستقل با نام `guide` دارد. این lane تست‌های دارای نام `guide` یا `help` را جدا از Calendar، Backup، FollowUp، Typography و Release اجرا می‌کند.

نتیجه عملی:
- خرابی راهنما می‌تواند سریع و مستقل تشخیص داده شود.
- بررسی Guide منتظر پایان laneهای نامرتبط نمی‌ماند.
- lane خرابِ نامرتبط مانع مشاهده نتیجه Guide نمی‌شود، چون matrix با `fail-fast: false` اجرا می‌شود.
- تست کامل پروژه همچنان در quality gate اجرا می‌شود و Guide جایگزین تست جامع نیست.
