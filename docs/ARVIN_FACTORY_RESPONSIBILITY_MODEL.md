# ARVIN Product Governance Model

## اصل حاکم

**کارخانه‌ها ابزار هستند؛ آروین محصول نهایی است.**

هدف کارخانه آروین و کارخانه NIRA ساخت خود کارخانه‌ها نیست؛ هدف آن‌ها افزایش سرعت، کیفیت، پایداری و توسعه محصول نهایی آروین است.

## کارخانه آروین

### مأموریت
ساخت محصول آروین.

### مسئولیت‌ها
- توسعه Featureها
- معماری نرم‌افزار
- UI/UX
- مدل داده
- Integration
- رفع Bug
- آماده‌سازی Release

معیار موفقیت:

> آیا کاربر نهایی تجربه بهتری از آروین دریافت می‌کند؟

## کارخانه NIRA

### مأموریت
کنترل هوشمند، هماهنگی، جلوگیری از انحراف و افزایش بهره‌وری توسعه.

### مسئولیت‌ها
- Reconcile وضعیت واقعی با هدف محصول
- کنترل انحراف معماری
- Quality Gate
- مدیریت Waveها
- ثبت Evidence
- تشخیص ریسک

NIRA نباید جایگزین محصول شود یا سرعت تولید را متوقف کند.

## قانون سرعت

کنترل باید باعث افزایش سرعت شود، نه ایجاد گلوگاه.

```
Build
 ↓
Fast Check
 ↓
Continue

Risk:
 ↓
Deep Validation
```

## چرخه همکاری

```
GitHub Commit
 ↓
NIRA Check
 ↓
Risk Detection
 ↓
ادامه توسعه آروین
```

## جلوگیری از تداخل

1. هیچ کارخانه‌ای مالک محصول نیست.
2. هر تغییر باید ارزش محصول آروین را افزایش دهد.
3. مسیرهای موازی که باعث دوگانگی محصول شوند ممنوع هستند.
4. بررسی‌ها باید مستمر باشند اما مانع حرکت توسعه نشوند.

## تقسیم Waveها

### Arvin Factory
مسئول ساخت Feature، تجربه کاربر و Integration.

### NIRA Factory
مسئول Automation، Quality، Reconcile و Risk Detection.
