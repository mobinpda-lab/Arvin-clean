## Design System

- فارسی و RTL کامل
- فونت VazirHarf v34.003
- رنگ اصلی: #4A4CAB

- سایه بسیار ظریف
- فضای سفید زیاد
- طراحی خلوت و کاربردی

## Quick Task Entry

ثبت سریع باید از همان مسیر canonical ساخت Task استفاده کند.

الزامات:

- Bottom Sheet واقعی Flutter
- RTL
- فوکوس خودکار عنوان
- ثبت فقط با عنوان
- انتخاب موعد، یادآور، تکرار، پروژه، دسته و برچسب
- فرم کامل همان Draft را دریافت کند

ثبت پیاپی:

- پنل بسته نشود
- عنوان پاک و آماده ثبت بعدی شود
- انتخاب‌های مشترک حفظ شوند
- Keyboard باقی بماند
- هر Task فقط یک بار ذخیره شود
- خطای ذخیره باعث از بین رفتن ورودی نشود
