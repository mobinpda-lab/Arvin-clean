# ARVIN Home Project Grouping Test Matrix

## هدف
تأیید اتصال نمای پروژه‌های صفحه خانه به معماری اصلی آروین بدون تغییر مدل Task.

## قوانین معماری

- منبع ارتباط پروژه و کار: ProjectStore / ProjectPlan.itemIds
- افزودن projectId به Task ممنوع است.
- تکثیر Task برای نمایش گروهی ممنوع است.

## سناریوها

### کار دارای پروژه
- یک Task به یک Project متصل است.
- باید فقط زیر همان پروژه نمایش داده شود.

### کار بدون پروژه
- Task بدون عضویت پروژه باید در گروه «بدون پروژه» نمایش داده شود.

### پروژه بدون کار
- پروژه خالی نباید باعث خطای نمایش شود.

### حفظ داده
- تغییر گروه‌بندی نباید Task، FollowUp یا تاریخچه را تغییر دهد.

## معیار پذیرش

- شمارش گروه‌ها از داده واقعی تولید شود.
- نمایش گروهی باعث افزایش تعداد واقعی Task نشود.
- Home Projection فقط خواندنی باشد.
