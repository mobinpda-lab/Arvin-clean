# قرارداد مرجع ظاهر آروین (Canonical Visual Reference Contract)

وضعیت: مرجع اصلی طراحی رابط کاربری

این سند مرجع نهایی ظاهر و رفتار رابط آروین است و در تعارض با اسناد قدیمی رابط کاربری، این سند اولویت دارد.

## هدف

هدف این قرارداد تبدیل تصاویر نصب واقعی آروین و تصمیم‌های نهایی محصول به معیار قابل اجرا برای توسعه است؛ نه ساخت موکاپ.

## اصول ثابت

- رابط کاملاً فارسی و RTL است.
- رنگ اصلی برند: `#4A4CAB`.
- فونت مصوب: VazirHarf v34.003.
- پس‌زمینه روشن، کارت سفید، گوشه نرم، سایه ظریف و فاصله‌گذاری منظم.
- اطلاعات UI باید از مدل‌ها و سرویس‌های واقعی تولید شود.
- تصویر مرجع برای چیدمان است؛ متن یا داده داخل تصویر نباید به صورت ثابت کپی شود.

## صفحه اصلی

ساختار نهایی:

- عنوان: بسم الله الرحمن الرحیم
- عنوان محصول: مدیریت کارها و پیگیری آروین
- اعلان در سمت چپ، منو در سمت راست.
- جستجوی گرد زیر عنوان.

کارت‌های آماری چهارگانه قدیمی خانه حذف هستند:

- کل
- فعال
- انجام شده
- عقب افتاده

این موارد فقط به عنوان فیلتر/گزارش قابل دسترسی هستند.

چهار ورودی گروه‌بندی اصلی:

1. زمان
2. پروژه‌ها
3. دسته‌ها
4. برچسب‌ها

ترتیب و جایگاه آن‌ها ثابت است و انتخاب هرکدام گروه‌بندی واقعی داده را تغییر می‌دهد.

## کارت کار

کارت باید شامل:

- وضعیت انجام
- عنوان
- پروژه یا دسته مرتبط
- موعد واقعی
- آخرین پیگیری در صورت وجود
- توضیح کوتاه در نبود پیگیری

لمس کارت فقط جزئیات را باز می‌کند.

## ثبت سریع

پنل ثبت سریع پایین صفحه و بالای صفحه‌کلید است.

الزامات:

- ثبت پیاپی بدون بسته شدن پنل.
- پاک شدن فقط عنوان و توضیحات بعد از ثبت موفق.
- حفظ انتخاب پروژه، دسته، برچسب، موعد، یادآوری و تکرار.
- جلوگیری از ثبت تکراری.
- حفاظت از پیش‌نویس هنگام خروج.

## جزئیات کار پیگیری‌دار

مرجع جدید:

- نمایش اطلاعات اصلی کار.
- کارت آخرین پیگیری.
- تاریخچه پیگیری از جدید به قدیم.
- افزودن پیگیری بدون حذف تاریخچه.
- دکمه‌های افزودن پیگیری، ویرایش و انجام کار.

## دفترچه

دو حالت مستقل:

- یادداشت ساده
- چک‌لیست

ویرایشگر یادداشت باید تمام صفحه و محتوامحور باشد.

## ناوبری پایین

پنج مقصد ثابت:

1. خانه
2. تقویم
3. دفترچه
4. اقدام بعدی
5. بیشتر

پروژه و دسته تب ششم نیستند.

## کنترل تداخل اسناد

هر سند قدیمی که با موارد زیر تعارض داشته باشد باید اصلاح یا علامت‌گذاری شود:

- چهار کارت آماری در خانه
- رابط‌های آزمایشی
- داده‌های ثابت نمونه
- صفحات موازی برای همان قابلیت

مدل‌های اصلی Task، FollowUp، Project، Category، Label و Notebook باید حفظ شوند.

## معیار پذیرش

تطابق نهایی فقط زمانی معتبر است که:

- روی اندروید واقعی اجرا شود.
- داده واقعی نمایش داده شود.
- تست ثبت سریع، پیگیری، یادداشت، گروه‌بندی و حفظ داده موفق باشد.
- اسکرین‌شات از اجرای واقعی ارائه شود.
