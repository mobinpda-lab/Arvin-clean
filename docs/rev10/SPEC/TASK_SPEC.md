# Task Specification
Task is independently creatable; Center, Project and Category assignments are optional. Preserve title, description, completion, due date, checklist, reminder, follow-ups, tags, people, extensionData and unknown historical keys. Editor must select/change/clear Center without unintentionally changing Project, Category, Tags, People or extensionData. Clearing preserves explicit NULL/absent semantics. Detail displays relationships and navigates only to existing detail surfaces. Quick Capture remains fast and does not require organization. Acceptance: create/edit/reopen, real SQLite assertions, due-date preservation and backup/restore proof.
