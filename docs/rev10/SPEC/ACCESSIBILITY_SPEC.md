# Accessibility Specification — measurable criteria
- TalkBack identifies controls, states, relationships and actions in Persian; focus order follows RTL visual/semantic order.
- Text/UI contrast meets WCAG AA targets.
- At 200% font scaling, primary flows remain operable without clipped text, hidden actions or horizontal overflow.
- Touch targets meet Android guidance (48dp minimum where applicable).
- Dialogs, menus, calendar controls and Task cards expose labels, hints, roles and selected/disabled states.
- Automated semantics/layout checks plus physical-device TalkBack evidence are required for acceptance.
