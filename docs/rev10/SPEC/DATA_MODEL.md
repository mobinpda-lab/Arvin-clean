# Data Model Specification
Status: consolidation in progress; no schema migration authorized. SQLite is canonical. Preserve stable identity, unknown/extension data, explicit NULL, absent key, empty value and concrete value as distinct states. Money uses integer minor units plus explicit currency; never floating-point persistence. UUIDv7 is investigation only: no ID migration until compatibility with FKs, historical rows, import/export and backup/restore is proven and owner-approved. Archive, soft delete and permanent delete are distinct. Schema changes require sequential versioned migrations, idempotency, transactions, rollback, FK checks and historical fixtures. Acceptance: exact data/ID parity, close/reopen, failure injection and independent restore.
