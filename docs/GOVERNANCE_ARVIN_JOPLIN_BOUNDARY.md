# مرز پروژه Arvin و Joplin

> وضعیت: قرارداد حاکمیتی  
> Issue: #1268  
> مرجع جداسازی: #1244

## 1. پروژه اصلی

مخزن `mobinpda-lab/Arvin-clean` مخزن محصول اصلی **Arvin** است.

تمام فرمان‌های ادامه، گزارش وضعیت، تصمیم‌های معماری و مسیر توسعه Arvin باید ابتدا از آخرین وضعیت همین مخزن و شاخه/PR/Commit مربوط به آن استخراج شوند.

## 2. Joplin پروژه جداست

Joplin محصول Arvin نیست.

مخزن `mobinpda-lab/joplin` فقط یک محیط مستقل برای آزمایش و توسعه Joplin است و نباید به‌عنوان مخزن اصلی Arvin تلقی شود.

کار Joplin نباید باعث تغییر مسیر توسعه هسته Arvin شود.

## 3. ممنوعیت وابستگی

هیچ کد، مدل، سرویس، دیتابیس، تنظیمات، مسیر اجرا یا وابستگی Joplin نباید وارد runtime یا build هسته Arvin شود.

همچنین Joplin نباید برای اجرا یا build به Arvin وابسته شود.

استفاده از تجربه یا دارایی عمومی Arvin در Joplin فقط با کپی مستقل و بدون وابستگی اجرایی مجاز است.

## 4. مسیریابی فرمان «ادامه»

قبل از هر اقدام با فرمان «ادامه»:

1. پروژه فعال از آخرین وضعیت GitHub تعیین شود.
2. مخزن، شاخه، آخرین Commit، PR و Issue فعال همان پروژه بررسی شود.
3. اگر موضوع Joplin است، فقط مسیر مستقل Joplin دنبال شود.
4. اگر موضوع Arvin است، مسیر اصلی `mobinpda-lab/Arvin-clean` دنبال شود.
5. بدون شواهد GitHub، پروژه فعال از یک مخزن به مخزن دیگر منتقل نشود.
6. بررسی یک پروژه نباید به‌طور خودکار ادامه پروژه دیگر محسوب شود.

## 5. گزارش‌دهی

وضعیت Arvin و Joplin باید جداگانه گزارش شود.

هیچ وضعیت، درصد پیشرفت، Commit، CI، APK یا نتیجه آزمایش یکی از این دو پروژه نباید به پروژه دیگر نسبت داده شود.
