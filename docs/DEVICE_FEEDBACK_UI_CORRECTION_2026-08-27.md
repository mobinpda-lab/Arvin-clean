# اصلاح بازخورد دستگاه واقعی آروین — 2026-08-27

Refs: #321, #326, #8, #253, #319

## منبع بازخورد
نسخه Release ساخته‌شده از مسیر #319 روی گوشی واقعی نصب شد. اسکرین‌شات و تست مستقیم کاربر چند فاصله واقعی میان Build و قرارداد تصویری/رفتاری آروین را آشکار کرد.

## اشکال‌های تأییدشده
1. انتخاب تاریخ پیگیری از `showDatePicker` میلادی/انگلیسی استفاده می‌کرد.
2. «بسم الله الرحمن الرحیم» در Home بیش از حد بالا و نزدیک ناحیه وضعیت سیستم دیده می‌شد.
3. میانبر Backup به‌صورت آیکن مستقل در AppBar صفحه اصلی قرار داشت، در حالی که باید از منوی برنامه در دسترس باشد.
4. `Dismissible` فقط `endToStart` را فعال کرده بود؛ روی RTL واقعی فقط یک حرکت فیزیکی کار می‌کرد و نتیجه آن Trash بود.
5. برای رفتار حرکت چپ/راست هیچ تنظیم قابل مشاهده‌ای در Settings وجود نداشت.

## اصلاح اجراشده
- Date picker مستقل و آفلاین شمسی/جلالی با ماه‌های فارسی، ارقام فارسی و هفته شنبه تا جمعه اضافه شد.
- تبدیل تاریخ میلادی ↔ جلالی روی `PersianDateFormatter` متمرکز شد؛ storage همچنان `DateTime` canonical فعلی است.
- تاریخ فارسی برای نصب بدون تنظیم قبلی، پیش‌فرض Iran-first است.
- Bismillah در یک title block با ارتفاع و offset صریح پایین‌تر قرار گرفت.
- آیکن Backup از AppBar حذف و ورودی `پشتیبان‌گیری و بازیابی` به Drawer اضافه شد؛ همان `ArvinBackupManager` قبلی استفاده می‌شود.
- Swipe کارت‌ها دوطرفه شد. در RTL پیش‌فرض:
  - حرکت فیزیکی به راست → سطل زباله
  - حرکت فیزیکی به چپ → بایگانی
- Settings برای هر جهت گزینه‌های `بایگانی`، `سطل زباله` و `بدون عمل` دارد.
- تنظیم Swipe در همان SharedPreferences تنظیمات و همان payload قابل حمل Backup ذخیره می‌شود؛ domain storage جدیدی ایجاد نشده است.
- حذف دائمی از Trash همچنان نیازمند تأیید صریح است.

## تست‌های افزوده/به‌روزشده
- تبدیل رفت و برگشت Gregorian/Jalali روی تاریخ 2026-08-27 = 1405/06/05.
- Widget test برای سطح کاملاً فارسی picker و انتخاب روز.
- regression test برای نبود Backup در Home و حضور آن در Drawer.
- regression test برای جایگاه جدید Bismillah.
- regression test برای هر دو جهت فیزیکی Swipe در RTL.
- persistence/portable-backup tests برای تنظیمات Swipe.
