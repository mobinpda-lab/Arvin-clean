## مواردی که هنوز «کامل‌شده» اعلام نمی‌شوند
### 1. پذیرش واقعی Quick Add
- موعد و یادآور باید روی گوشی واقعی با تاریخ/ساعت انتخاب شوند.
- تست کد موجود است، اما پذیرش نصب فعلی گوشی باید جداگانه اثبات شود.

### 2. Home
- چهار بخش زمان/پروژه‌ها/دسته‌ها/برچسب‌ها در main وجود دارند.
- فیلترهای ترکیبی و انطباق کامل بصری با مرجع نهایی هنوز نیازمند پذیرش واقعی هستند.
- clipping کارت‌ها و ظاهر نهایی فقط با مشاهده گوشی قابل تأیید است.

### 3. تقویم
- زیرساخت همگام‌سازی در main وجود دارد.
- رفتار نهایی «تقویم مقصد انتخاب‌شده»، ایجاد/ویرایش/حذف و پذیرش گوشی هنوز باید end-to-end اثبات شود.
- تغییر مقصد تقویم قبل از هر تغییر معماری/Storage نیازمند تصمیم معماری مستقل است.

### 4. Notebook
- فیلتر Project/Category/Tag و عملیات برچسب/دسته در کد فعلی وجود دارند.
- یکسان‌سازی کامل taxonomy و Roll Box داخل ویرایشگر و سه ابزار inline هنوز باید ممیزی و پذیرش شود.
- حذف Checklist/Shopping/Travel فقط بعد از dependency audit و بدون حذف داده.

### 5. Typography / Appearance
- فونت پیش‌فرض VazirHarf و کنترل اندازه متن در main وجود دارند.
- پذیرش بصری app-wide و تطبیق کامل با مرجع نهایی هنوز اثبات نشده است.

### 6. Release Gate
- CI دقیقِ main فعلی در endpoint بررسی‌شده run تازه‌ای گزارش نکرد؛ بنابراین سبز بودن CI برای SHA فعلی ادعا نمی‌شود.
- Release-Ready کل محصول هنوز اثبات نشده است.
