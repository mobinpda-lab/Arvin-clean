# ARVIN UI Implementation Audit Phase 2

Date: 2026-09-14

## هدف
این مرحله برای تطبیق عمیق‌تر قرارداد نهایی آروین با ساختار واقعی پروژه انجام می‌شود.

## حوزه بررسی

### Home
- بررسی ساختار صفحه اصلی
- تطبیق چیدمان با مرجع نصب واقعی
- جلوگیری از بازگشت کارت‌ها و الگوهای قدیمی متعارض

### Quick Entry
- بررسی مسیر ثبت سریع
- حفظ پیش‌نویس
- ثبت پیاپی بدون بستن پنل
- اتصال به مسیر اصلی ذخیره Task

### Task Detail / FollowUp
- بررسی اتصال نمایش کار با مدل‌های موجود
- حفظ تاریخچه پیگیری
- جلوگیری از حذف داده هنگام ویرایش

### Notebook
- بررسی یادداشت و چک‌لیست
- حفظ ذخیره‌سازی فعلی
- تطبیق ویرایشگر با مرجع طراحی

## معیار وضعیت
هر قابلیت باید یکی از وضعیت‌های زیر را دریافت کند:

- Documented
- Implemented
- Data Connected
- Tested
- Android Verified

## قانون
وجود فایل یا ویجت به معنی تکمیل قابلیت نیست. تکمیل فقط پس از اتصال داده، تعامل واقعی و تست پذیرفته می‌شود.

## مرحله بعد
تکمیل جدول صفحه به صفحه شامل مسیر فایل، کلاس، اختلاف با مرجع و اقدام اصلاحی.
