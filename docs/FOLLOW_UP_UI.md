# Follow-up UI contract

## هدف

هر کار باید بتواند تاریخچه پیگیری داشته باشد و در فهرست کارها فقط آخرین پیگیری به‌همراه ساعت آن به‌صورت خلاصه نمایش داده شود.

## قرارداد نمایش

- اگر تاریخچه خالی است، بخش آخرین پیگیری نمایش داده نشود.
- آخرین پیگیری بر اساس `dateTime` انتخاب شود، نه ترتیب لیست.
- تاریخ و ساعت هر دو نمایش داده شوند.
- متن پیگیری در صورت وجود بعد از تاریخ/ساعت نمایش داده شود.
- تاریخچه کامل در صفحه جزئیات کار قرار خواهد گرفت.

## مدل داده

`ArvinTask.followUps` منبع اصلی تاریخچه است.

`ArvinTask.followUpDate` فعلاً برای سازگاری با داده‌های قدیمی حفظ شده و هنگام `addFollowUp` با جدیدترین پیگیری هماهنگ می‌شود.
