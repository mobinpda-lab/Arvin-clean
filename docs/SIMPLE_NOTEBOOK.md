# دفترچه یادداشت ساده آروین

## وضعیت بررسی

در بازنگری `main` در 2026-08-14، فایل یا صفحه فعال مستقلی برای «دفترچه یادداشت ساده» در درخت فعلی پروژه پیدا نشد. این قابلیت به‌عنوان **قابلیت محصولی سابق/مورد انتظار** ثبت شده و فعال‌سازی UI آن باید مستقل از مهاجرت Task/FollowUp انجام شود.

## قرارداد محصول

دفترچه یادداشت ساده باید شامل این موارد باشد:

- موضوع/عنوان یادداشت
- متن یادداشت
- تاریخ و ساعت ثبت که هنگام ایجاد به‌صورت خودکار از سیستم پر می‌شود
- تاریخ و ساعت قابل ویرایش توسط کاربر
- پس از ورود اطلاعات، ذخیره‌سازی خودکار انجام شود
- پس از خروج از صفحه، یادداشت به‌صورت فقط‌خواندنی نمایش داده شود
- در مراجعه بعدی، دکمه «یادداشت»/«ویرایش یادداشت» حالت ویرایش را فعال کند
- فعال/غیرفعال بودن قابلیت دفترچه یادداشت از تنظیمات قابل کنترل باشد
- تاریخ و ساعت با تجربه فارسی/شمسی پروژه هماهنگ باشد
- تاریخ و ساعت یادداشت **فقط داده داخلی آروین** هستند و نباید به Google Calendar، تقویم سیستم یا تقویم گوشی ارسال/ثبت شوند
- Backup/Restore آینده باید داده‌های Note را نیز حفظ کند

## تفکیک زمان‌ها

`SimpleNote.dateTime` زمان مربوط به خود یادداشت است. این زمان می‌تواند هنگام ایجاد از ساعت سیستم مقداردهی شود و سپس توسط کاربر ویرایش شود.

این زمان با `FollowUp.dateTime` یا `FollowUp.nextFollowUp` یکی نیست و نباید به‌صورت ضمنی به Reminder یا Calendar تبدیل شود.

## معماری پیشنهادی

لایه دامنه و ذخیره‌سازی باید مستقل از UI پیاده‌سازی شود تا با مهاجرت Task/FollowUp تداخل نکند.

کلید ذخیره‌سازی:

`arvin.simple_notes`

مدل پایه `SimpleNote` شامل `id`, `title`, `body`, و `dateTime` است.

## قانون Read-only / Edit

- حالت اولیه ایجاد: ویرایش فعال
- با تغییر عنوان/متن/تاریخ/ساعت: ذخیره خودکار
- خروج از صفحه: نمایش فقط‌خواندنی
- مراجعه بعدی: فقط با اقدام صریح کاربر، حالت ویرایش فعال شود
- تنظیمات می‌تواند کل قابلیت دفترچه یا رفتار ویرایش را فعال/غیرفعال کند؛ UI نهایی باید این تصمیم را به‌صورت شفاف نمایش دهد

## قانون Calendar

یادداشت‌ها در Calendar آروین نمایش داده نمی‌شوند مگر اینکه در آینده به‌صورت یک تصمیم محصولی صریح و جداگانه تصویب شود. همچنین هیچ Event برای Google Calendar یا تقویم سیستم ساخته نمی‌شود.

## جلوگیری از دوباره‌کاری

قبل از فعال‌سازی UI باید implementationهای `arvin-task-tracker` و `daftar-peygiri` با این قرارداد مقایسه شوند. Calendar فعلی `Arvin-clean` نیز نباید بدون regression مشخص بازنویسی شود.
