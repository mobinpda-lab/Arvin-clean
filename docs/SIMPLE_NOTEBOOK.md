# دفترچه یادداشت ساده آروین

## وضعیت بررسی

در بازنگری `main` در 2026-08-14، فایل یا صفحه فعال مستقلی برای «دفترچه یادداشت ساده» در درخت فعلی پروژه پیدا نشد. `main.dart` هنوز مسیر قدیمی `ArvinTask` را در اختیار دارد و قابلیت Note به‌صورت یک feature مستقل در وضعیت فعلی مخزن قابل مشاهده نیست.

بنابراین این قابلیت به‌عنوان **قابلیت محصولی سابق/مورد انتظار** ثبت می‌شود، نه اینکه فرض شود همین حالا در UI فعال است.

## قرارداد محصول

دفترچه یادداشت ساده باید شامل این موارد باشد:

- موضوع/عنوان یادداشت
- متن یادداشت
- تاریخ و ساعت ثبت که هنگام ایجاد به‌صورت خودکار از سیستم پر می‌شود
- تاریخ و ساعت قابل ویرایش توسط کاربر
- ذخیره خودکار هنگام ورود/ویرایش اطلاعات
- پس از خروج از صفحه، یادداشت به‌صورت فقط‌خواندنی نمایش داده شود
- در مراجعه بعدی، دکمه «ویرایش یادداشت» حالت ویرایش را فعال کند
- فعال/غیرفعال بودن این رفتار از تنظیمات قابل کنترل باشد
- تاریخ و ساعت نمایش با تجربه فارسی/شمسی پروژه هماهنگ باشد
- Backup/Restore آینده باید داده‌های Note را نیز حفظ کند

## معماری پیشنهادی

لایه دامنه و ذخیره‌سازی باید مستقل از UI پیاده‌سازی شود تا با مهاجرت Task/FollowUp تداخل نکند.

کلید ذخیره‌سازی پیشنهادی:

`arvin.simple_notes`

مدل پایه `SimpleNote` شامل `id`, `title`, `body`, و `dateTime` است. این Commit فقط پایه دامنه/Repository/تست را ثبت می‌کند و هنوز UI، Settings یا تغییر `main.dart` انجام نمی‌دهد.

## جلوگیری از دوباره‌کاری

قبل از فعال‌سازی UI باید implementationهای `arvin-task-tracker` و `daftar-peygiri` دوباره با این قرارداد مقایسه شوند. Calendar فعلی `Arvin-clean` نیز نباید بدون regression مشخص بازنویسی شود.

## مراحل بعدی

1. اتصال Repository به Settings
2. اضافه‌کردن feature flag برای فعال/غیرفعال بودن Note
3. UI ایجاد/ویرایش/خواندن
4. ذخیره خودکار و read-only پس از خروج
5. تست Widget و persistence
6. اتصال Backup/Restore
7. تست E2E و APK
