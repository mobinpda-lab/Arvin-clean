# ثبت سریع پیگیری از دفتر — ۲۰۲۶-۰۸-۲۵

## برش اجرایی

مسیر قابل‌استفاده `دفتر پیگیری → ثبت پیگیری → متن/نتیجه → ذخیره`
به `main` اضافه می‌شود. اگر فقط یک کار وجود داشته باشد، انتخاب آن خودکار است؛
برای چند کار، کاربر ابتدا کار مقصد را انتخاب می‌کند.

## منبع داده

- صفحه ورودی موجود از PR قدیمی #46 دوباره استفاده می‌شود؛ آن PR به‌تنهایی به
  persistence متصل نبود و با `main` فعلی قابل ادغام نیست.
- ذخیره فقط از مسیر موجود `FollowUpRepository.add` انجام می‌شود.
- داده در همان `FollowUps[]` داخل همان envelope و کلید `arvin.tasks` باقی
  می‌ماند؛ مدل، کلید یا Storage تازه‌ای ایجاد نمی‌شود.
- تاریخ و ساعت اولیه از سیستم گرفته می‌شود و در صفحه ورودی قابل ویرایش است.

## مرز این برش

این PR فایل‌های Backup، `main.dart` و `models/task.dart` را تغییر نمی‌دهد.
اتصال مستقیم دکمه ثبت پیگیری به هر کارت Home، نمایش شمسی کامل صفحه ورودی و
Reminder مستقل، برش‌های بعدی هستند.

## رگرسیون

تست Widget مسیر واقعی ثبت را تا بررسی JSON ذخیره‌شده پوشش می‌دهد و حالت نبودن
کار نیز بدون ایجاد داده موازی کنترل می‌شود.
