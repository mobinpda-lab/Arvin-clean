# ARVIN MASTER OPERATING COMMAND (AMOC) — Compatibility Bridge

**Status:** Subordinate compatibility/reference bridge. It is not a competing top-level protocol.

The governing product-operating authority is [ARVIN MASTER PRODUCT OPERATING PROTOCOL (AMPOP) v5.0](ARVIN_MASTER_PRODUCT_OPERATING_PROTOCOL.md). The detailed operational procedure is [ARVIN PROJECT OPERATING PACKAGE](../ARVIN_PROJECT_OPERATING_PACKAGE.md).

AMOC was the earlier name for the governing command. To avoid two competing constitutions, follow AMPOP v5.0 for product identity, domain invariants, data safety, approval, evidence and release gates. Follow the Operating Package for detailed execution, validation and continuity procedures.

The user command **ادامه آروین** triggers live GitHub inspection and safe continuation of the highest-value feasible unfinished product work. It does not authorize unsafe/destructive changes, merging or release without required approval.

This bridge preserves existing links and history. It does not claim product acceptance or release readiness.
