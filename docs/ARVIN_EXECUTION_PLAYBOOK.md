# Arvin Execution Playbook v38.0

## Execution Cycle
CHECK -> DECIDE -> SPLIT -> EXECUTE -> VERIFY -> RECORD -> CONTINUE

## Parallel Rule
Independent lanes execute simultaneously.
Dependent work follows coordinated flow.
Foundation work follows controlled flow.

## Lanes
- Product Lane
- Foundation Lane
- Quality Lane
- Delivery Lane

## Fast Path
Change -> Test -> CI -> Merge

## Controlled Path
Analysis -> Review -> Change -> Validation -> CI -> Merge

## Objective
Produce working software faster without reducing quality.
