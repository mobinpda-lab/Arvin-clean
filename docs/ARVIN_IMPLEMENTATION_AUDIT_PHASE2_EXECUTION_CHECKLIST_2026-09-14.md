# ARVIN Implementation Audit Phase 2 Execution Checklist

## هدف
تطبیق قرارداد نهایی آروین با پیاده‌سازی واقعی Flutter و جلوگیری از انحراف از مرجع طراحی.

## اصول ثابت
- ظاهر مرجع نصب واقعی آروین است.
- قرارداد محصول نهایی مرجع رفتار است.
- اسناد قدیمی متعارض فقط برای سابقه نگهداری می‌شوند.
- مدل‌ها و سرویس‌های موجود بازاستفاده می‌شوند و معماری موازی ساخته نمی‌شود.

## دامنه بررسی

### Home
- بررسی Header
- جستجو
- چهار حالت گروه‌بندی
- کارت کار
- ناوبری پایین

### Quick Entry
- پنل بالای صفحه‌کلید
- ثبت پیاپی
- حفظ انتخاب‌ها
- جلوگیری از ثبت تکراری
- رفتار Back اندروید

### Task Detail / FollowUp
- نمایش آخرین پیگیری
- تاریخچه
- افزودن پیگیری بدون حذف تاریخچه

### Notebook
- یادداشت ساده
- چک‌لیست
- ویرایشگر
- حفظ داده

### Calendar / Next Action
- اتصال به داده واقعی
- جلوگیری از منطق ساختگی
