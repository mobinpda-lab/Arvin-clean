# Arvin v1 Status

## Project
- Repository: mobinpda-lab/Arvin-clean
- Platform: Flutter
- Goal: Professional, stable, extensible Persian RTL assistant application.

## Development Rules

1. Review project context before changes.
2. Make small, controlled, reversible changes.
3. Run tests and GitHub Actions after changes.
4. Document important changes.
5. Never claim commits, pushes, or workflow execution unless actually completed.

## GitHub Write Access Policy

If GitHub write access is unavailable:
- Report it immediately.
- Do not claim commits or repository changes.
- Continue analysis and preparation.
- Apply prepared changes after access returns.

## Current Priorities

1. Calendar stabilization
2. CI/CD health
3. Data migration safety
4. UI/UX completion

## Development Flow

Review -> Small Change -> Test -> Workflow -> Commit -> Review
