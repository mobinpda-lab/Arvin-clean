# ARVIN IMPLEMENTATION MATRIX

| بخش | وضعیت | توضیح |
|---|---|---|
| قرارداد نهایی UI/UX | فقط مستند شده | ARVIN FINAL PRODUCT CONTRACT مرجع اجرایی است |
| Home چهار نما | کد نوشته شده / نیازمند تطبیق | زمان، پروژه، دسته، برچسب باید Grouping واقعی داشته باشند |
| حذف کارت آماری | فقط مستند شده | کارت های آماری قدیمی نباید به Home برگردند |
| Quick Entry | کد نوشته شده / نیازمند پذیرش | ثبت پیاپی، Draft مشترک و ذخیره Canonical باید تأیید شوند |
| Full Editor | نیازمند بررسی | باید همان Draft را دریافت کند و مسیر ذخیره جدا نسازد |
| Task Detail | نیازمند تکمیل | لمس کارت باید جزئیات را باز کند نه ویرایش مستقیم |
| FollowUp Detail | فقط مستند شده / نیازمند اجرا | Timeline، آخرین پیگیری و افزودن پیگیری باید واقعی شوند |
| Swipe RTL | نیازمند تست | جهت ها و انتقال به Trash باید روی اندروید بررسی شود |
| Notebook | نیازمند بررسی | حفظ Storage موجود و دو حالت یادداشت/چک لیست |
| Calendar | نیازمند بررسی | تقویم شمسی و تفکیک Task/FollowUp/Reminder |
| Settings | نیازمند بررسی | فقط قابلیت های واقعی نمایش داده شوند |
| Android Evidence | انجام نشده | Build، Screenshot و Video واقعی لازم است |
