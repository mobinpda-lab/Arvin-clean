# ARVIN FINAL PRODUCT CONTRACT

## Authority

این سند مرجع نهایی اجرای رابط و تجربه کاربری آروین است.
هدف: تبدیل Arvin-clean به محصول Flutter واقعی، نه موکاپ یا پیشنهاد طراحی.

## معماری

هسته موجود حفظ می‌شود:

- Task
- FollowUp
- Project
- Category
- Tag
- Notebook
- Calendar
- Storage
- Services

ساخت مسیر موازی برای مدل، ذخیره‌سازی یا سرویس ممنوع است.

## Design System

- فارسی و RTL کامل
- VazirHarf v34.003
- رنگ اصلی #4A4CAB
- پس زمینه #F8F8FB
- کارت سفید، گوشه نرم، سایه ظریف

## Home

کارت‌های آماری قدیمی حذف می‌شوند:

- کل
- فعال
- انجام‌شده
- عقب‌افتاده

اما گروه زمانی عقب‌افتاده در نمای زمان باقی می‌ماند.

چهار نمای اصلی:

1. زمان
2. پروژه‌ها
3. دسته‌ها
4. برچسب‌ها

انتخاب هر نما باید Grouping واقعی داده را تغییر دهد.

افزودن کار از گروه باید Context همان گروه را به Draft منتقل کند.

## Quick Entry

ثبت سریع و فرم کامل باید یک Task Draft و یک مسیر ذخیره اصلی داشته باشند.

ثبت موفق:

- پنل بسته نشود
- عنوان و توضیحات همان کار پاک شوند
- فوکوس به عنوان برگردد
- انتخاب‌های مشترک حفظ شوند
- ثبت تکراری جلوگیری شود

## Task Detail و FollowUp

صفحه جزئیات کار شامل:

- مشخصات کار
- آخرین پیگیری
- تاریخچه پیگیری از جدید به قدیم
- افزودن پیگیری
- ویرایش
- انجام کار

ثبت پیگیری جدید فقط به تاریخچه همان Task اضافه می‌شود.

## Notebook و Calendar

Notebook، یادداشت و چک‌لیست واقعی خود پروژه حفظ می‌شود.

Calendar باید Task، FollowUp، Reminder و Event را از هم جدا نگه دارد.

## Acceptance

هیچ قابلیت بدون شواهد واقعی تکمیل اعلام نمی‌شود.

سطوح وضعیت:

- فقط مستند شده
- کد نوشته شده
- تست شده
- روی اندروید تأیید شده
