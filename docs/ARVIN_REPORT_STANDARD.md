# استاندارد گزارش آروین

## قانون اجرای GitHub
هر پیشرفت اجرایی باید دارای اثر قابل مشاهده در GitHub باشد:
Commit واقعی یا Workflow واقعی یا Pull Request واقعی.

## زنجیره اجرای رسمی
Branch → Commit → Pull Request → Workflow → Validation → Merge

## اصول
- عدم ثبت Commit صوری
- حفظ Branch Protection
- تغییرات کوچک و Rollback پذیر
- حفظ Source of Truth اصلی
- گزارش فقط بر اساس وضعیت واقعی GitHub

## اصل سرعت
اجرای موازی + همزمان + سریع با حفظ کنترل معماری.
