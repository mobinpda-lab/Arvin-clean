# اصول راهبردی پروژه آروین

## اصل اصلی

**کارخانه وسیله است؛ آروین محصول نهایی است.**

## هدف

تمام فعالیت‌های توسعه، اتوماسیون، ابزارها و زیرساخت‌ها باید در خدمت تکمیل، پایداری و انتشار محصول آروین باشند.

## قوانین اجرایی

- توسعه Factory نباید به یک محصول مستقل تبدیل شود.
- هر تغییر باید ارزش مستقیم برای محصول آروین ایجاد کند.
- Product Work نسبت به Factory Work اولویت دارد.
- Automation باید باعث کاهش خطا، جلوگیری از تداخل و افزایش سرعت توسعه محصول شود.
- ایجاد Feature، Storage، Model یا مسیر معماری موازی بدون نیاز واقعی ممنوع است.
- قبل از Merge هر تغییر مهم، شواهد واقعی GitHub شامل Test، Build یا Validation مربوطه بررسی شود.
- در شرایط نامطمئن، سیستم باید Fail Closed رفتار کند.

## معیار تصمیم‌گیری

قبل از انجام هر کار باید پاسخ این سؤال مشخص باشد:

«آیا این کار آروین را به یک محصول نهایی بهتر نزدیک می‌کند؟»

اگر پاسخ منفی باشد، آن کار در اولویت قرار نمی‌گیرد.
