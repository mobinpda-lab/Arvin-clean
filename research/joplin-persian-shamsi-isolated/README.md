# Joplin Persian-Shamsi — فضای مستقل

> این پوشه یک فضای تحقیق و توسعه مستقل برای افزونه Joplin است و **جزء محصول Arvin محسوب نمی‌شود**.

## هدف

ساخت یک افزونه مستقل برای Joplin با هدف:
- نمایش بهتر متن فارسی و راست‌به‌چپ؛
- استفاده از VazirHarf؛
- بررسی و پیاده‌سازی نمایش تاریخ هجری شمسی/جلالی؛
- حفظ کامل داده، زمان‌های ذخیره‌شده و همگام‌سازی Joplin.

## مرز قطعی با Arvin

1. این پوشه نباید به هیچ کلاس، سرویس، مدل، دیتابیس، تنظیمات یا مسیر اجرایی Arvin وابسته شود.
2. هیچ import یا dependency از کد اجرایی Arvin مجاز نیست.
3. هیچ تغییر در `lib/`، `pubspec.yaml`، مدل‌ها، دیتابیس، تنظیمات یا runtime Arvin برای اجرای Joplin مجاز نیست.
4. افزونه باید به‌صورت یک پروژه مستقل Joplin ساخته و بسته‌بندی شود.
5. وابستگی معکوس نیز ممنوع است: Joplin نباید هیچ وابستگی اجرایی به Arvin پیدا کند.
6. هر فایل، تنظیمات ساخت و وابستگی مربوط به Joplin باید داخل همین فضای مستقل یا در یک مسیر کاملاً مشخص و مستقل نگهداری شود.
7. کد یا دارایی Arvin فقط در صورت نیاز و با مجوز/شرایط مناسب می‌تواند به‌صورت مستقل بازاستفاده شود؛ استفاده مستقیم از runtime آروین ممنوع است.
8. این شاخه برای تحقیق و توسعه مستقل است و تا زمانی که جداسازی و پذیرش فنی اثبات نشده، نباید وارد `main` آروین شود.

## کنترل فونت ویرایشگر

بررسی API رسمی Joplin نشان داد که `CodeMirrorControl` دسترسی مستقیم به `CodeMirror 6 EditorView` و امکان ثبت/اجرای command و افزودن extension را می‌دهد، اما API رسمی افزونه نقطه‌ای برای افزودن مستقیم گزینه به **فهرست فونت داخلی Joplin** ارائه نمی‌کند. بنابراین این پروژه از مسیر رسمی افزونه استفاده می‌کند: یک تنظیم انتخابی با گزینه‌های `Joplin default` و `VazirHarf` و یک فرمان CodeMirror 6 که مستقیماً روی `CodeMirrorControl.editor` اعمال می‌شود. روی Android نیز `EditorToolbar` و `joplin.commands` از مسیر رسمی افزونه پشتیبانی می‌شوند.

در نتیجه راه‌حل CSS-only حذف شده است؛ CSS فقط فایل فونت را معرفی می‌کند و تغییر واقعی `fontFamily` توسط افزونه CodeMirror 6 انجام می‌شود.

## مرجع فنی

Joplin ساخت افزونه با `generator-joplin` و ساخت خروجی با `npm run dist` را مستند کرده و Manifest امکان اعلام پشتیبانی از `mobile` و `desktop` را دارد. این پروژه باید همین مسیر مستقل را دنبال کند.
